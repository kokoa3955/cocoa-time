# 制約・誤差・未検証事項

## 自動化の境界

- PWAはiPhone全体の使用履歴を取得しません。ユーザーが登録し、ファイルとして取り込んだアプリだけです。
- ショートカットのログ保存は自動化できますが、PWAへはファイル選択で取り込みます。朝に開くだけで未取り込みログが反映されることはありません。
- 標準スクリーンタイムの値・制限設定をWebから読んだり書いたりしません。
- 「勉強開始」は集中モード／OS制限を変更せず、PWA内の開始時刻だけを保存します。
- Web Push、ローカル通知、背景監視、独自の強制ブロックはありません。
- 署名済みのインポート可能な.shortcutは同梱していません。

## 推定のルール

- 起動・終了の対から経過時間を推定。ペアが揃っても、ロック中・バックグラウンド・Picture in Picture・バックグラウンド再生などを判別できません。
- ショートカットの実行遅延が開始・終了時刻に含まれます。精度保証や誤差の上限はありません。
- 開始しかない、終了しかない、次の起動が先に来た、別アプリと重複、同時刻に複数起動、設定した連続時間上限を超える場合は要確認として時間集計から除外。
- 欠落終了を次のアプリ開始で自動補完しません。そのため過小計上もあります。
- 同一 appId/type/正規化した日時 のイベントは1件に統合。ミリ秒まで同一の本物の再実行も区別できません。
- 入力の順番ではなくタイムスタンプ順で再構成。時計の変更で順序が壊れた場合、検出できる欠落や矛盾は除外しますが、もっともらしい誤記録は判別できません。
- 同じ時刻のアプリ切り替えは、現在のアプリの終了を先に扱います。新しいアプリの0秒ペアは0秒として扱います。
- 日本時間の00:00で分割。時差や夏時間のある地域でも集計は常にAsia/Tokyo相当（UTC+09:00）です。
- 手動転記はアプリ・日ごとに唯一。自動推定を置き換え、加算しません。削除すると推定が再び使われます。
- 手動の日合計を時間帯へ分配しません。時間帯グラフは、その日の手動優先アプリを除いたペア推定のみ。
- 起動回数は記録されたopenイベント数。実際の起動回数・持ち上げ回数ではありません。
- 最終使用は最終イベント時刻で、記録後に使っていないことは保証しません。

## 分析の解釈

- 未記録日は「未記録」。日平均は記録がある日で割ります。記録がある日でも、一部の利用しか記録されていない可能性があります。
- 全時間が不確かで除外された日には0分と要確認を併記。使用しなかったとは言えません。
- 達成日数は「記録済み合計が目標内で要確認なしの日数」。実際の全利用に対する達成ではありません。
- 週は月曜始まり。今週・今月は当日まで。前週・前月は全期間なので比較の母数が違います。
- 日ごとの記録範囲・対象アプリが異なる場合、増減率は習慣の改善／悪化を直接示しません。
- 平日・休日比較は月〜金と土日の区別だけで、祝日は判定しません。
- 31日より長い選択範囲のグラフは連続する複数日を合算し、最大31本程度の棒にします。タップで期間と値を表示。
- 勉強時間は開始〜終了の経過時間。実際に集中した時間を測っていません。終了忘れは編集可能。
- 勉強中の避けたいアプリは、開始時点の対象リストと、取り込み済みのペア推定が重なる部分だけです。手動値を勉強中に割り当てません。
- 学習成績、健康、心理、原因に関する推論は行いません。

## 保存・プライバシー

- IndexedDBは保存容量不足、ブラウザ設定、OSによる削除等で消える可能性があります。永続化要求が成功しても永久保証ではありません。
- 別の端末／ブラウザ／URLでデータを共有しません。Safariとホーム画面アプリの保存先も同一とは限りません。
- 同じオリジン内ではIndexedDB名は共通です。同じドメインの別パスに本アプリを複数置いた場合、独立した利用者領域としては使わないでください。
- ローカル保存はアプリ独自に暗号化していません。端末のロック・OSの保護に依存します。JSON/CSVも平文です。
- iCloud Driveを記録先にした場合、そのログは自分のiCloudへ同期されます。「一切クラウドを使わない」構成とは異なります。
- ページ配信時には通常のWebアクセスが発生し、配信業者が接続情報等を扱うことがあります。本アプリの利用履歴は送信しません。
- 取り込み元ファイルの再選択だけではデータが反映されず、確認画面で適用が必要です。破損入力は全体を拒否します。
- 保存競合を検出した場合は再読み込みが必要。複数タブで同時編集する運用は避けてください。

## 上限

- 保存イベント10万件、登録アプリ1000件、1回のファイル読み込み20MB・1000ファイル。
- 期間指定は最大367日。数年分を見る場合は期間を分ける。
- 手動・勉強履歴の一覧は最新100件・60件を表示。完全バックアップには全件を含む。
- 2万イベントの自動テストはLinux上で実施。iPhoneでの大量データ性能は未測定。
- 大量ファイルの選択・アーカイブ管理は手間がかかります。1イベント1ファイルを採用したことによる実用上のトレードオフです。
