# iPhone標準の制限設定

確認日：2026-10-30。Cocoa Timeの目標を変えても、以下のOS設定は変わりません。PWAは設定状態を読み取れないため「制限中」と断定表示しません。

## まず画面を確認

「設定」→「一般」→「情報」でiOSのバージョンを確認。その後「設定」→「スクリーンタイム」を開きます。

iOS 27のApple公式日本語資料では「許容時間」「スクリーンタイムのスケジュール」が案内されています。従来の「App使用時間の制限」「休止時間」が表示される場合は後半の手順を使います。管理・ファミリー設定や複数端末のOSが異なると利用できる項目が変わります。

## iOS 27の新しい画面

1. 「スクリーンタイム」→「許容時間」を開く。
2. カテゴリと1日の時間枠を設定する。追加は「カテゴリを管理」から行う。
3. 「スクリーンタイムのスケジュール」で「スケジュール」をオンにし、曜日と時間枠を作る。
4. 勉強・夜間などの各時間枠に、使用できるカテゴリを指定する。
5. 「常に許可」で、必要な連絡先やアプリを確認する。

公式説明はカテゴリ単位の許容時間が中心です。この新しい画面でアプリごとに任意の独立した分数を設定できることは、今回確認した資料から保証できません。PWAのアプリ別目標と1対1で一致しない場合は、iOS側はカテゴリ制限、PWA側はアプリ別の振り返りとして使います。新機能には、利用するAppleデバイスやファミリーのデバイスのOSバージョン条件があります。

公式： https://support.apple.com/ja-jp/guide/iphone/iphb0c7313c9/27/ios/27

## 従来の「App使用時間の制限」がある画面

1. 「設定」→「スクリーンタイム」で「アプリとWebサイトのアクティビティ」をオンにする。
2. 「App使用時間の制限」→「制限を追加」。
3. カテゴリを開いて、制限するアプリを選ぶ。アプリ別の独立した上限なら1つずつ追加する。複数選択時は合計枠として扱われる場合があるため、独立した上限と誤認しない。
4. 「次へ」→時間を設定→「追加」。曜日ごとの違いは「曜日別に設定」。
5. スクリーンタイム設定をパスコードで保護し、表示される場合は「使用制限終了時にブロック」を有効にする。表記や配置はOSにより異なる。
6. 最初は短い上限で実際に制限画面が出ることを確認し、その後希望の分数に戻す。

## 従来の「休止時間」がある画面

1. 「設定」→「スクリーンタイム」→「休止時間」。
2. スケジュールを有効にし、毎日または曜日別の開始・終了を設定。
3. スクリーンタイムのパスコードを設定し、「休止時間中にブロック」を確認。
4. 「常に許可」で必要なアプリ・連絡を残す。

従来の休止時間は、任意のアプリ群それぞれに別の時間帯を何本も設定する汎用ルール機能ではありません。勉強中のSNS、深夜の動画などを完全に独立制御できるとは限りません。

従来画面の公式： https://support.apple.com/ja-jp/guide/iphone/-iphb0c7313c9/ios

## 勉強モードとの使い方

1. Cocoa Timeで「勉強モード」→「勉強をはじめる」。
2. コントロールセンターから勉強用の集中モードをオンにする。
3. 必要なら設定アプリからiOSのスケジュール／休止時間を適用する。
4. 終わったらCocoa Timeで「勉強を終了する」。集中モードは別途オフにする。
5. 後でCSVを取り込むと、勉強区間に重なった「避けたいアプリ」のペア推定を表示する。

集中モードは通知等を抑える機能です。Cocoa Timeは自動で切り替えません。PWAの状態をショートカットから無人で読み取れるとの仮定も置いていません。

## 回避可能性と確認

- 自分がパスコードや設定を管理している場合、制限の延長・解除が可能です。
- オートメーションを停止してもiOS標準の制限は別に動きますが、PWAの記録は欠けます。
- Cocoa Timeの警告は、取り込んだ記録に対する画面内の表示です。
- ファミリー等で管理されている場合は、管理者が許可した範囲で操作してください。
- 設定後は、対象アプリを使い、制限画面が実際に出るか確認してください。PWAは確認できません。

## 標準値の手動転記

標準スクリーンタイムの使用状況で日別・対象iPhone・対象アプリの時間を確認し、Cocoa Timeの「履歴」へ入力します。iOS 27では「1日の平均」から日／週の概要を見る案内があります。複数端末の合計をiPhone単体の記録と混ぜないでください。

公式： https://support.apple.com/ja-jp/guide/iphone/iphbfa595995/27/ios/27
